# Why there is no application front end

The record is a dependency graph, a change window, human decisions and evidence from each run. Ask the agent for the next task or an overdue owner. It runs the same CLI and returns the answer here.

The generated HTML files are read-only snapshots. They do not refresh, accept edits, send notifications or execute infrastructure. A dedicated screen adds live multi-user updates, mobile use, offline capture, drag and drop and account permissions. Those need a separate implementation. Enterprise DNA can build a web front end and agreed integrations around the owned database.

This base coordinates human-operated changes. It does not replicate Cutover automation, failover, chat, integrations, linked runbook execution or automatic resource scheduling. Generated critical paths assume unlimited parallel resources and ignore fixed-date constraints. Use a trained operator and a reviewed change plan. The software does not make a migration safe by itself.
